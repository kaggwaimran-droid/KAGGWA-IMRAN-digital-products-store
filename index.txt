## Run locally

No build tools or package installation are required.

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. Use the navigation link to open the book catalogue.

For a more realistic local test, serve the files with any static HTTP server.

## Publish with GitHub Pages

1. Create a GitHub repository and upload **all files in this folder** to the repository root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your publishing branch (usually `main`) and the `/(root)` folder, then save.
5. Wait for GitHub Pages to publish the site. The homepage will be `index.html`; the book page will be available at `/kdp-books.html`.

Keep `index.html` and `kdp-books.html` in the same directory so navigation works correctly.

## Before launch

- Open every Gumroad and Amazon link and confirm that it points to the correct, live listing.
- Check current prices, availability, descriptions, and book cover images.
